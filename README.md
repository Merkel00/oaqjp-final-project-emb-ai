
# Final Project

## Emotion Detection Using IBM Watson NLP

This project is an AI-based web application developed
using Python, IBM Watson NLP, and Flask.

The application analyzes the emotions expressed in
English text and identifies five categories:

- Anger
- Disgust
- Fear
- Joy
- Sadness

The application also identifies the dominant emotion.

## Technologies Used

- Python 3
- IBM Watson NLP
- Flask
- Requests
- Unittest
- Pylint

## Project Features

1. Emotion detection using Watson NLP.
2. Formatted emotion prediction output.
3. Python package implementation.
4. Unit testing.
5. Web application using Flask.
6. Error handling for invalid input.
7. Static code analysis.
